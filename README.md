# Tapzag

Tiny one-tap zigzag. Stay on the diamonds.

Tap anywhere to start. The marble runs on its own. Tap again to turn. Miss a corner and you drop. Distance plus copper motes is the score.

## Play

Open [index.html](index.html) in a browser, or after GitHub Pages is on:

**https://chive55.github.io/tapzag/**

On a phone, tap the screen. On a keyboard, space / A / D also turns.

## Files

- `index.html` — the whole game
- `favicon.svg` — tab icon

Best score is stored in `localStorage` as `tapzag-best`.
